# سَنَد | SANAD — نظرة عامة على المشروع

> **الحالة:** Sprint 0 — Foundation (الأساس). المشروع قيد التطوير المبكّر.

## الفكرة

**سَنَد (SANAD)** هو مساعد شخصي ذكي يعمل في مرحلته الأولى عبر **WhatsApp**.
الهدف: مساعد عربي يفهم المستخدم، يتذكّر، وينفّذ المهام نيابةً عنه من داخل محادثة واتساب.

## الرؤية (المنتج المستقبلي)

> هذه القدرات تصف المنتج النهائي المستهدف، **ولم تُنفَّذ بعد** في هذا الـ Sprint.

يُرسل المستخدم مستقبلًا:

- رسائل نصية
- ملاحظات صوتية (Voice Notes)
- صور
- فواتير
- ملفات PDF
- روابط ومواقع

ويستطيع سَنَد:

- فهم طلب المستخدم بالعربية
- إنشاء وإدارة المهام
- إنشاء التذكيرات وإرسالها في مواعيدها
- حفظ ذاكرة طويلة المدى
- تسجيل المصاريف وقراءة الفواتير
- إرسال ملخّص يومي
- الرد نصيًا أو صوتيًا
- تنفيذ الأدوات عبر **AI Function Calling**

## المستخدمون المستهدفون

الأفراد الذين يريدون مساعدًا شخصيًا **عربيًا** لإدارة حياتهم اليومية وأعمالهم من خلال واتساب.

## نطاق Sprint 0 — Foundation (المُنفَّذ فعليًا)

Sprint 0 يُرسي الأساس التقني فقط، دون أي منطق منتج:

- مشروع Laravel (PHP 8.4) مع Livewire و Tailwind CSS ودعم RTL.
- بنية تحتية محلية: PostgreSQL و Redis عبر Docker Compose.
- تهيئة الطوابير (Queues)، المجدول (Scheduler)، الكاش، والسجلات (Logging)، و Horizon.
- Health Check على `GET /api/health`.
- صفحة رئيسية مؤقتة بالعربية RTL.
- جودة الكود: Pint + Pest + GitHub Actions.
- توثيق كامل.

راجع [ROADMAP.md](ROADMAP.md) لما هو قادم، و[ARCHITECTURE.md](ARCHITECTURE.md) للمعمارية.

## خارج نطاق Sprint 0

لم يُنفَّذ أيٌّ ممّا يلي بعد (سيأتي في Sprints لاحقة):
تكامل WhatsApp، تكامل OpenAI، الصوت، المهام، التذكيرات، الذاكرة، الفوترة،
المصادقة (Authentication)، لوحة التحكم (Dashboard)، النشر (Deployment).
